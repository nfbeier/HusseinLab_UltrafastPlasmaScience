# Software

This directory contains the source code for the control system of the Portable LIBS (Laser-Induced Breakdown Spectroscopy) unit. The software is responsible for controlling the operation of the unit, processing data, and providing user interfaces for interaction.

## Contents

- **src**: Source code files for the control system.
- **tests**: Test suites and scripts for validating the functionality of the software.
- **README.md**: Information about the software, including how to build, install, and use it.

Feel free to explore the software codebase and contribute any improvements, bug fixes, or new features you may have.

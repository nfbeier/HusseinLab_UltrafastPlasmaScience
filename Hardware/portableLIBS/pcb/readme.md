# PCB Designs

This directory contains the Printed Circuit Board (PCB) designs for any custom hardware components used in the Portable LIBS (Laser-Induced Breakdown Spectroscopy) project. The PCB designs are essential for manufacturing the hardware components required for the system.

## Folder Structure

- **project_name.pro**: KiCad project file containing metadata and settings for the PCB project.
- **project_name.kicad_pcb**: Main PCB layout file in KiCad's native format.
- **project_name.sch**: Schematic file representing the electrical connections and components used in the PCB design.
- **project_name-cache.lib**: Cached library file generated by KiCad.
- **project_name-cache.dcm**: Cached component metadata file generated by KiCad.
- **project_name.kicad_wks**: Workspace file containing additional settings and preferences.
- **gerber**: Gerber files used for manufacturing the PCBs.
  - Contains subdirectories for different PCB manufacturing layers (e.g., top layer, bottom layer, silkscreen, solder mask, etc.).
- **drill**: Drill files specifying the locations of holes to be drilled on the PCB.
- **3d_models**: Optional directory for 3D models of PCB components.

## Usage

To work with the PCB designs, open the KiCad project file (`project_name.pro`) using the KiCad Electronic Design Automation (EDA) software. You can then view, modify, and export the PCB layout and associated files for manufacturing.

Feel free to explore the PCB designs and contribute any improvements or modifications to enhance the hardware components of the project.

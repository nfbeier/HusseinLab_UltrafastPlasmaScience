# Portable LIBS Unit

This repository contains code and hardware designs for the Portable LIBS (Laser-Induced Breakdown Spectroscopy) unit currently in development. It encompasses both the control system's source code and the PCB (Printed Circuit Board) files for any custom hardware utilized in the project.

## Folder Structure

- **software**: Contains the source code for the control system of the Portable LIBS unit.
- **pcb**: Holds the PCB files for any custom hardware components used in the project.
- **docs**: Reserved for documentation related to the project.

## Usage

- **Software**: To work with the control system code, navigate to the `software` directory.
- **PCB Design**: For PCB-related work, navigate to the `pcb` directory.
- **Documentation**: Refer to the `docs` directory for any project-related documentation.
